# 📊 Value Bet Scanner — Premium PWA
Professional dark-themed Progressive Web App for finding positive EV bets.

## ✨ Features
- 🎨 **Premium dark glass design** — gradients, blur, smooth animations
- 📱 **Full PWA support** — installable on phone & desktop
- 📈 Real-time odds scanning via API
- 🧮 Automatic EV % calculation
- 🛡️ Safe Option logic with confidence ratings
- 🔍 Filter: All / Safe Only / Strong Value
- 🚀 Ready for Netlify — just upload & deploy

## 🚀 Setup
1. Get API key → https://the-odds-api.com/ (free tier works)
2. Open `config.js` → replace `YOUR_API_KEY_HERE` with your key
3. Upload all 6 files to GitHub
4. Connect GitHub repo to Netlify → Deploy!

## 📁 Files
- `index.html` — App interface
- `styles.css` — Premium styling
- `app.js` — Logic & API calls
- `config.js` — API key & settings
- `manifest.json` — PWA manifest
- `README.md` — Instructions
